# Build Order

1. Commit source JSONL and normalized v0.2 derived files.
2. Create Mapbox account and tokens.
3. Run geocoding script.
4. Review geocoding audit.
5. Export valid GeoJSON.
6. Build backend search API.
7. Build frontend Mapbox UI.
8. Create Dify custom OpenAPI tool.
9. Add custom tool inside Resource Navigator Agent.
10. Test Dify follow-up behavior.
